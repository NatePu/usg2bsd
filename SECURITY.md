# Security policy

usg2bsd is a lab fork of OpenBSD for one router, the Ubiquiti USG-3P. It is not
for production use and has no releases; only `main` is maintained.

## Reporting a vulnerability

Report security problems privately through GitHub: open the
[Security tab](https://github.com/NatePu/usg2bsd/security) and choose
"Report a vulnerability". Please do not open a public issue or pull request
for a vulnerability.

Problems in OpenBSD itself, outside this fork's changes in `patches/`, belong
to the OpenBSD project: see <https://www.openbsd.org/security.html>.
